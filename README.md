# 🚀 CI Pipeline Project

A simple Node.js project demonstrating a CI pipeline using GitHub Actions. It runs automated tests whenever code is pushed to the `main` branch.

---

## ⚙️ CI Workflow
- Checkout code
- Setup Node.js (v16)
- Install dependencies
- Run tests (`npm test`)

---

## 🧪 Test Example
- `index.js` prints a message
- `test.js` waits for some seconds and logs output

---

## 🔄 Workflow File
Uses GitHub Actions CI pipeline to automate testing on every push.

---

## 🛠 Tech Stack
- Node.js
- GitHub Actions
- YAML
